# English Literature Experiment

An experimental editorial interface built from the catalogue metadata of `Yuri-code-dot/English-library-`.

## What is here

- Real catalogue records for 33 works
- Author, period, genre, subject, theme, source, licence and reading-link metadata
- Working **Read now** links for records that expose a `readingUrl`
- Search across title, author, period, genre, subject and themes
- Genre filters
- Subject/domain index
- Interactive book-spread section
- Metadata modal for each catalogue record
- Editorial timeline
- Experimental design lab
- Responsive mobile layout

## Data provenance

The catalogue records are adapted from the `src/data/books.ts` data model in `English-library-`. Public-domain reading links remain external links to the source recorded by the library. Copyrighted works are presented as catalogue metadata only when the source library does not provide a reading URL.

## Design direction

Cream paper, black ink, red annotations, fine grid lines, oversized editorial typography, physical-book metaphors and interaction-first layouts.

This repository is intentionally separate from the production library so the visual system can evolve without destabilising the main application.
